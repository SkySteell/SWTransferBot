# Бот-агрегатор заказов (этапы 2-3: фильтры и расчёт по калькулятору)

Файлы: bot.py (запуск), order_parser.py (разбор), filters.py (фильтры), settings.py (настройки), calc.py (расчёт по правилам SWTCalcBot),
cards.py (карточка), make_session.py (одноразово), test_parser.py и test_filters.py (проверки).
Загружать на хостинг: bot.py, order_parser.py, filters.py, settings.py, calc.py, cards.py, requirements.txt.

## Переменные окружения
Обязательные: API_ID, API_HASH (my.telegram.org), SESSION_STRING (make_session.py),
BOT_TOKEN (@BotFather), OWNER_ID (@userinfobot).
Необязательные: TZ_OFFSET (часовой пояс, по умолчанию 3 = Москва), DATA_DIR (папка settings.json).

## Кнопки внизу экрана бота
«⚙️ Настройки»: меню фильтров (сумма, города откуда/куда, время, неизвестное, тарифы ₽/км и срочность, пауза).
«📊 Статистика»: сколько заказов распознано, отсеяно и по каким причинам.
Пустой список городов откуда или куда означает «любые».

## Запуск
1. Откройте бота в Telegram и нажмите /start.
2. Запустите bot.py: придёт «Бот запущен».
3. Задайте фильтры кнопкой «⚙️ Настройки». Пока фильтры не заданы, придут все распознанные заказы.

## Расчёт по калькулятору
Карточка приходит сразу со строкой «Считаю…», через несколько секунд она дописывается:
стоимость по калькулятору, расстояние и разница с ценой заказа. Расстояния берутся с карты
(Nominatim + OSRM, результаты кэшируются в geocache.json). Если города не найдены, используются
километры из текста заказа, если они там указаны. Платные дороги в расчёт не входят.
Тарифы ₽/км и надбавка за срочность меняются кнопкой «🧮 Тарифы».
