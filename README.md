# Бот-агрегатор заказов (этап 2: фильтры)

Файлы: bot.py (запуск), order_parser.py (разбор), filters.py (фильтры), settings.py (настройки),
cards.py (карточка), make_session.py (одноразово), test_parser.py и test_filters.py (проверки).
Загружать на хостинг: bot.py, order_parser.py, filters.py, settings.py, cards.py, requirements.txt.

## Переменные окружения
Обязательные: API_ID, API_HASH (my.telegram.org), SESSION_STRING (make_session.py),
BOT_TOKEN (@BotFather), OWNER_ID (@userinfobot).
Необязательные: TZ_OFFSET (часовой пояс, по умолчанию 3 = Москва), DATA_DIR (папка settings.json).

## Кнопки внизу экрана бота
«⚙️ Настройки»: меню фильтров (сумма, города откуда/куда, время, неизвестное, пауза).
«📊 Статистика»: сколько заказов распознано, отсеяно и по каким причинам.
Пустой список городов откуда или куда означает «любые».

## Запуск
1. Откройте бота в Telegram и нажмите /start.
2. Запустите bot.py: придёт «Бот запущен».
3. Задайте фильтры кнопкой «⚙️ Настройки». Пока фильтры не заданы, придут все распознанные заказы.
